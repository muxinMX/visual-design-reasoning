# Optional Image Prompt Template

Select and combine only fields relevant to the task. A short request may need only one direct paragraph.

## Generation brief

- **Subject and goal:** what the image must show and why
- **Defining form:** silhouette, proportion, components, clothing, or visual identity
- **Action and spatial relationship:** pose, interaction, scale, overlap, and depth
- **Composition and viewpoint:** framing, camera angle, perspective, focal hierarchy, and negative space
- **Environment:** setting and only the supporting elements needed
- **Visual treatment:** style characteristics, color, material, lighting, and atmosphere
- **Preserve:** confirmed identity, structure, layout, or project constraints
- **Avoid:** contradictions, unwanted elements, or generation risks
- **Tool adaptation:** include only when a target tool is named and its syntax is known

## Local edit variant

- **Target:** exact region or property to change
- **From → To:** current state and desired state
- **Boundary consistency:** geometry, edge, perspective, material, reflection, and lighting requirements
- **Preserve unchanged:** every non-target identity, object, layout, background, and lighting property
- **Prevent:** spillover, redesign, duplication, deformation, or unrelated additions
