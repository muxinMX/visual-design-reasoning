# Visual Analysis

Use this module to understand one or more visual references before creating or editing.

## Select the analysis mode

- **Reconstruction analysis:** identify the visual variables required to recreate a comparable image without claiming hidden production facts.
- **Style extraction:** separate transferable visual language from depicted content.
- **Multi-reference synthesis:** assign a role to each reference, identify compatible and conflicting traits, and propose a coherent synthesis.
- **Subject structure:** analyze silhouette, proportion, volumes, features, clothing or components, material, and recognition cues.

## Observe in useful layers

Choose only layers relevant to the request:

- subject, object, or information hierarchy;
- silhouette, geometry, proportion, scale, and spatial relationships;
- color roles, value grouping, saturation, and temperature;
- material, surface treatment, edge language, line or brush behavior;
- composition, camera position, perspective, depth, and negative space;
- lighting direction, softness, contrast, atmosphere, and focal control;
- narrative cue, mood, function, and likely audience effect.

Mark uncertain camera values, software, construction techniques, authorship intent, and causal claims as estimates rather than facts.

## Style extraction

Separate:

1. **Content-specific traits** — the particular character, object, setting, logo, costume, or event.
2. **Transferable traits** — shape grammar, abstraction level, edge treatment, palette logic, material response, lighting logic, density, and composition habits.

A reusable style description should omit source-specific identities and copyrighted character details. Describe observable traits instead of relying on a creator or studio name when concrete visual language is sufficient.

## Multi-reference work

For every reference, state its role: identity, pose, composition, style, color, material, lighting, environment, or another explicit contribution. Resolve conflicts before merging. Never average incompatible traits without explaining the resulting hierarchy.

## Stage-aware outputs

- **Analyze:** observations, uncertainty, key transferable traits, and risks only.
- **Explore:** several coherent ways to apply the analysis.
- **Refine:** a consolidated visual specification.
- **Prompt:** pass the confirmed specification to `prompt-generation.md`.
